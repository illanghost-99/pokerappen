# Poker Night – Flutter

Komplett Flutter-app för Poker Night.

## Setup
1. `flutter pub get`
2. Lägg till `GoogleService-Info.plist` i `ios/Runner`
3. Ändra Bundle ID till `com.illanghost.pokernight`
4. `flutter run`

## Features
- Sign in with Apple
- Skapa & se pokersessioner
- Realtids Firestore
- Mörkt tema
- Redo för vidareutveckling (bord, buy-in, countdown, export)
